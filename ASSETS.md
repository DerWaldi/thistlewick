# Third-party assets

Everything in the game is built from code unless listed here: primitives, procedural geometry, canvas-painted portraits, synthesised sound effects, and procedurally sequenced music ("The Thistlewick Waltz" and "The Tumbling Vaults" in `src/engine/music.ts`). Only CC0 assets are allowed.

To use a recorded track instead of the synthesised music, place it at `public/music/<mood>.mp3` (`hub`, `dungeon` or `title`) and add a row below.
